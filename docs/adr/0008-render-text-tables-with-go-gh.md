# Render text tables with go-gh

jiro renders every tabular text result through `github.com/cli/go-gh/v2/pkg/tableprinter`: an actual or explicitly forced TTY receives a viewport-aware table, while non-TTY output is headerless, untruncated TSV and an empty result writes zero bytes. Commands define opaque `Fixed` columns for dedicated copyable identifiers and structural labels, while descriptive fields and mixed detail-table `VALUE` columns are `Flexible`; headers and cells are sanitized into safe single-line presentation without changing normalized JSON. jiro detects terminals with `github.com/mattn/go-isatty` using `IsTerminal(fd) || IsCygwinTerminal(fd)`, retains `golang.org/x/term` for terminal width and hidden password input, accepts only the exact strict boolean tokens documented for `JIRO_FORCE_TTY`, falls back to 80 columns when a forced terminal width is unavailable, and keeps colors outside this decision.

[ADR-0012](0012-render-issue-details-as-man-style-sections.md) supersedes this decision for `issue show` text output only.
